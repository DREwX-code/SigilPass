SigilPass

SigilPass יוצר סיסמאות אקראיות ישירות בדפדפן. התאימו אורך ותווים, מלאו טפסים בלחיצה או השתמשו ב-“Safer” למילוי ללא תצוגה או העתקה.

סיסמה מוכנה לשימוש

  • יצירה מאובטחת קריפטוגרפית : Web Crypto ללא מעבר למחולל אקראי שאינו מאובטח.
  • אורך מותאם אישית : 12–64 תווים, עם אותיות גדולות, ספרות וסמלים לבחירה.
  • מילוי ישיר : כפתורים לצד שדות סיסמה, כולל שדות אימות שזוהו.
  • מד אנטרופיה : הערכה שמרנית בביטים ושל מספר הצירופים האפשריים.
  • העתקה אוטומטית לבחירה : כבויה כברירת מחדל; אפשר להפעיל בהגדרות.

שני מצבים לפי הצורך

“Standard” מאפשר לבחור אורך, סוגי תווים, תצוגת סיסמה והעתקה אוטומטית.

“Safer” מוסיף הגנות:

  • מינימום: 24 תווים, עם אפשרות להגדיל את האורך.
  • אותיות גדולות וקטנות, ספרות וסמלים.
  • ללא תצוגה מקדימה או העתקה ללוח.
  • מילוי ישיר בלבד בהקשר מאובטח, כגון HTTPS.
  • ניקוי נתוני סקריפט זמניים כשהכרטיסייה מוסתרת או כשעוזבים את הדף.

העדפות “Standard” נשמרות במעבר בין מצבים.

ממשק שמתאים לכם

  • ערכת נושא כהה כברירת מחדל או כחולה.
  • הגדרות במקטעים מתקפלים.
  • אפשר להסתיר בנפרד את הכפתור הצף ואת כפתורי השדות.
  • בחירה בין 46 שפות וגרסאות אזוריות.
  • יצירה והגדרות דרך תפריט מנהל הסקריפטים.

התקנה

  1. התקינו את הסקריפט בעזרת מנהל סקריפטים למשתמש. המלצה: Tampermonkey.
  2. פתחו את ההגדרות בכפתור הצף או בתפריט המנהל ובחרו אפשרויות.
  3. השתמשו בכפתור לצד שדה סיסמה למילוי ישיר.

פרטיות ומגבלות

היצירה מקומית: הסקריפט אינו שולח בקשות רשת ואינו שומר סיסמאות באחסון קבוע. המנהל שומר רק העדפות. SigilPass הוא מחולל, לא כספת סיסמאות.

האתר המקבל את הטופס יכול לקרוא את הסיסמה שמולאה. “Safer” מצמצם חשיפה בממשק ובלוח, אך אינו הופך אתר זדוני לאמין.

קוד מקור ותמיכה

עיינו בקוד המקור ב-GitHub או דווחו על בעיה. ציינו דפדפן, מנהל סקריפטים וצעדי שחזור בלי לשתף סיסמאות.
