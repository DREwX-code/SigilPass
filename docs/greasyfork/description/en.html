SigilPass

SigilPass generates random passwords directly in your browser. Customize their length and characters, fill forms in one click, or use “Safer” mode for direct filling without preview or copying.

A password ready to use

  • Cryptographically secure generation : Web Crypto, with no fallback to an insecure random generator.
  • Customizable length : 12–64 characters, with optional uppercase letters, numbers and symbols.
  • Direct filling : buttons beside password fields, including detected confirmation fields.
  • Entropy indicator : a conservative estimate in bits and estimated possible combinations.
  • Optional automatic copy : disabled by default; enable it in settings if needed.

Two modes for your needs

“Standard” lets you choose length, character categories, password preview and automatic copying.

“Safer” applies additional protections:

  • Minimum: 24 characters, with the option to increase the length.
  • Uppercase and lowercase letters, numbers and symbols included.
  • No password preview or clipboard copying.
  • Direct filling only, in a secure context such as HTTPS.
  • Temporary script data cleared when the tab is hidden or you leave the page.

Your “Standard” preferences are preserved when switching modes.

An interface that adapts to you

  • Dark theme by default or a blue theme.
  • Settings organized in collapsible sections.
  • Floating bubble and field buttons can be hidden separately.
  • Language selection in settings, with 46 interface locales.
  • Generation and settings accessible through the userscript manager menu.

Installation

  1. Install the script using a userscript manager. Recommendation: Tampermonkey.
  2. Open settings from the floating bubble or manager menu, then choose your options.
  3. Use a button beside a password field to fill it directly.

Privacy and limitations

Generation is local: the script makes no network requests and does not persistently store passwords. Only preferences are saved by the userscript manager. SigilPass is a generator, not a password vault.

A password filled into a form is accessible to the receiving website. “Safer” reduces exposure in the interface and clipboard; it does not make a malicious website trustworthy.

Source code and support

View the source code on GitHub or report an issue. Include your browser, userscript manager and reproduction steps, without sharing any password.
