SigilPass

SigilPass는 브라우저에서 무작위 비밀번호를 생성합니다. 길이와 문자를 조절하고 한 번의 클릭으로 양식을 채우거나, “Safer”로 표시와 복사 없이 직접 입력하세요.

바로 사용할 비밀번호

  • 암호학적으로 안전한 생성 : Web Crypto를 사용하며 안전하지 않은 난수 생성기로 대체하지 않습니다.
  • 길이 설정 : 12~64자, 대문자·숫자·기호를 선택할 수 있습니다.
  • 직접 입력 : 감지된 확인란을 포함한 비밀번호 입력란 옆에 버튼을 제공합니다.
  • 엔트로피 표시 : 보수적으로 추정한 비트 수와 가능한 조합 수입니다.
  • 선택적 자동 복사 : 기본적으로 꺼져 있으며 필요하면 설정에서 켤 수 있습니다.

용도에 맞는 두 모드

“Standard”에서는 길이, 문자 유형, 비밀번호 표시와 자동 복사를 선택할 수 있습니다.

“Safer”는 추가 보호를 적용합니다.

  • 최소: 24자이며 길이를 늘릴 수 있습니다.
  • 대문자, 소문자, 숫자와 기호를 모두 포함합니다.
  • 비밀번호 미리보기와 클립보드 복사를 하지 않습니다.
  • HTTPS 같은 보안 컨텍스트에서 직접 입력만 허용합니다.
  • 탭이 숨겨지거나 페이지를 떠나면 스크립트의 임시 데이터를 지웁니다.

모드를 바꾸어도 “Standard” 설정은 유지됩니다.

사용자에 맞춘 인터페이스

  • 기본 어두운 테마 또는 파란 테마입니다.
  • 설정을 접을 수 있는 구역으로 구성했습니다.
  • 떠 있는 버튼과 입력란 버튼을 따로 숨길 수 있습니다.
  • 설정에서 46개 언어 및 지역 변형을 선택할 수 있습니다.
  • 스크립트 관리자 메뉴에서 생성과 설정에 접근할 수 있습니다.

설치

  1. 사용자 스크립트 관리자로 설치하세요. 권장: Tampermonkey.
  2. 떠 있는 버튼이나 관리자 메뉴에서 설정을 열어 옵션을 선택하세요.
  3. 비밀번호 입력란 옆의 버튼으로 직접 채우세요.

개인정보 보호와 한계

생성은 로컬에서 이루어집니다. 스크립트는 네트워크 요청을 보내거나 비밀번호를 영구 저장하지 않습니다. 관리자는 설정만 저장합니다. SigilPass는 생성기이며 비밀번호 보관함이 아닙니다.

양식을 받는 사이트는 입력된 비밀번호를 읽을 수 있습니다. “Safer”는 인터페이스와 클립보드의 노출을 줄일 뿐 악성 사이트를 신뢰할 수 있게 만들지는 않습니다.
