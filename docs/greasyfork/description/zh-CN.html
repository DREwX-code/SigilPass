SigilPass

SigilPass直接在浏览器中生成随机密码。自定义长度和字符，一键填写表单，或启用“Safer”模式，在不显示、不复制密码的情况下直接填入。

随时可用的密码

  • 密码学安全生成 : 使用Web Crypto，不会回退到不安全的随机生成器。
  • 自定义长度 : 12至64个字符，可选择大写字母、数字和符号。
  • 直接填入 : 在密码字段及检测到的确认字段旁提供按钮。
  • 熵指标 : 保守估计的比特数和可能组合数。
  • 可选自动复制 : 默认关闭，需要时可在设置中开启。

按需选择两种模式

“Standard”模式允许选择长度、字符类别、密码显示及自动复制。

“Safer”模式提供额外保护：

  • 最少：24个字符，可以继续增加长度。
  • 包含大写字母、小写字母、数字和符号。
  • 不预览密码，也不复制到剪贴板。
  • 仅在HTTPS等安全上下文中直接填入。
  • 标签页隐藏或离开页面时，清理脚本的临时数据。

切换模式时保留“Standard”偏好设置。

适合你的界面

  • 默认深色主题或蓝色主题。
  • 设置按可折叠章节组织。
  • 悬浮按钮和字段按钮可分别隐藏。
  • 在设置中选择46种语言及地区变体。
  • 通过用户脚本管理器菜单访问生成和设置。

安装

  1. 使用用户脚本管理器安装脚本。建议: Tampermonkey。
  2. 通过悬浮按钮或管理器菜单打开设置，选择所需选项。
  3. 点击密码字段旁的按钮直接填入。

隐私与限制

密码在本地生成：脚本不发送网络请求，也不持久保存密码。管理器仅保存偏好设置。SigilPass是生成器，不是密码保险库。

接收表单的网站可以读取填入的密码。“Safer”减少界面和剪贴板中的暴露，但不会让恶意网站变得可信。
