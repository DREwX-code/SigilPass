SigilPass

SigilPass သည် ဘရောက်ဇာတွင် ကျပန်းစကားဝှက်များ ဖန်တီးပေးသည်။ အရှည်နှင့် အက္ခရာများကိုရွေးပြီး ဖောင်များကို တစ်ချက်နှိပ်ဖြည့်ပါ၊ သို့မဟုတ် ပြသခြင်း၊ ကူးယူခြင်းမရှိသော “Safer” ကိုသုံးပါ။

အသင့်သုံးနိုင်သော စကားဝှက်

  • ကုဒ်ဝှက်စနစ်အရ လုံခြုံသောဖန်တီးမှု : Web Crypto သုံးပြီး မလုံခြုံသော ကျပန်းဖန်တီးစနစ်သို့ မပြောင်းပါ။
  • အရှည်ချိန်ညှိနိုင်ခြင်း : 12–64 လုံး၊ အက္ခရာအကြီး၊ ဂဏန်းနှင့် သင်္ကေတများ ရွေးနိုင်သည်။
  • တိုက်ရိုက်ဖြည့်ခြင်း : တွေ့ရှိသော အတည်ပြုအကွက်များအပါအဝင် စကားဝှက်အကွက်ဘေးတွင် ခလုတ်များ။
  • အင်ထရိုပီပြစနစ် : ဘစ်နှင့် ဖြစ်နိုင်သောပေါင်းစပ်မှုများအတွက် သတိထားခန့်မှန်းချက်။
  • ရွေးချယ်နိုင်သော အလိုအလျောက်ကူးယူမှု : မူလအတိုင်းပိတ်ထားပြီး လိုအပ်လျှင် ဆက်တင်တွင်ဖွင့်နိုင်သည်။

လိုအပ်ချက်အလိုက် မုဒ်နှစ်ခု

“Standard” တွင် အရှည်၊ အက္ခရာအမျိုးအစား၊ စကားဝှက်ပြသမှုနှင့် အလိုအလျောက်ကူးယူမှု ရွေးနိုင်သည်။

“Safer” သည် အပိုကာကွယ်မှုများ ပေးသည်။

  • အနည်းဆုံး: 24 လုံး၊ အရှည်ထပ်တိုးနိုင်သည်။
  • အက္ခရာအကြီး၊ အသေး၊ ဂဏန်းနှင့် သင်္ကေတများ ပါဝင်သည်။
  • စကားဝှက်ကြိုတင်ပြသခြင်း သို့မဟုတ် ကလစ်ဘုတ်ကူးယူခြင်း မရှိပါ။
  • HTTPS ကဲ့သို့ လုံခြုံသောအခြေအနေတွင် တိုက်ရိုက်ဖြည့်ခြင်းသာ။
  • တက်ဘ်ဝှက်သည့်အခါ သို့မဟုတ် စာမျက်နှာမှထွက်သည့်အခါ ယာယီစခရစ်ဒေတာ ရှင်းလင်းသည်။

မုဒ်ပြောင်းသော်လည်း “Standard” စိတ်ကြိုက်ဆက်တင်များ မပျောက်ပါ။

ချိန်ညှိနိုင်သော မျက်နှာပြင်

  • မူလအမှောင်ပုံစံ သို့မဟုတ် အပြာရောင်ပုံစံ။
  • ခေါက်သိမ်းနိုင်သော ဆက်တင်ကဏ္ဍများ။
  • ရေပေါ်ခလုတ်နှင့် အကွက်ခလုတ်များ သီးခြားဝှက်နိုင်သည်။
  • ဘာသာစကားနှင့် ဒေသပုံစံ 46 မျိုး ရွေးနိုင်သည်။
  • စခရစ်မန်နေဂျာမီနူးမှ ဖန်တီးမှုနှင့် ဆက်တင်များ ဝင်နိုင်သည်။

ထည့်သွင်းခြင်း

  1. အသုံးပြုသူစခရစ်မန်နေဂျာဖြင့် ထည့်သွင်းပါ။ အကြံပြုချက်: Tampermonkey။
  2. ရေပေါ်ခလုတ် သို့မဟုတ် မန်နေဂျာမီနူးမှ ဆက်တင်ဖွင့်ပြီး ရွေးချယ်ပါ။
  3. စကားဝှက်အကွက်ဘေးရှိ ခလုတ်ဖြင့် တိုက်ရိုက်ဖြည့်ပါ။

ကိုယ်ရေးလုံခြုံမှုနှင့် ကန့်သတ်ချက်များ

စက်တွင်း၌ ဖန်တီးသည်။ စခရစ်က ကွန်ရက်တောင်းဆိုမှုမပို့၊ စကားဝှက်ကို အမြဲတမ်းမသိမ်းပါ။ မန်နေဂျာက စိတ်ကြိုက်ဆက်တင်သာ သိမ်းသည်။ SigilPass သည် ဖန်တီးစနစ်ဖြစ်ပြီး စကားဝှက်သိမ်းတိုက်မဟုတ်ပါ။

ဖောင်လက်ခံသည့်ဆိုက်သည် ဖြည့်ထားသောစကားဝှက်ကို ဖတ်နိုင်သည်။ “Safer” က မျက်နှာပြင်နှင့် ကလစ်ဘုတ်တွင် ပေါက်ကြားမှုလျှော့ပေးသော်လည်း အန္တရာယ်ရှိဆိုက်ကို ယုံကြည်ရစေမည်မဟုတ်ပါ။
