SigilPass

SigilPass બ્રાઉઝરમાં જ રેન્ડમ પાસવર્ડ બનાવે છે. લંબાઈ અને અક્ષરો પસંદ કરો, એક ક્લિકથી ફોર્મ ભરો અથવા બતાવ્યા અને નકલ કર્યા વિના “Safer” વાપરો.

વાપરવા તૈયાર પાસવર્ડ

  • ક્રિપ્ટોગ્રાફિક રીતે સુરક્ષિત નિર્માણ : Web Crypto; અસુરક્ષિત રેન્ડમ જનરેટરનો વિકલ્પ નહીં.
  • પસંદગીની લંબાઈ : 12–64 અક્ષરો, મોટા અક્ષરો, આંકડા અને ચિહ્નો પસંદ કરી શકાય.
  • સીધું ભરવું : ઓળખાયેલા પુષ્ટિ ખાનાં સહિત પાસવર્ડ ખાનાં પાસે બટનો.
  • એન્ટ્રોપી સૂચક : બિટ અને સંભવિત સંયોજનોનો સાવચેત અંદાજ.
  • વૈકલ્પિક આપમેળે નકલ : મૂળભૂત રીતે બંધ; જરૂર પડે સેટિંગમાં ચાલુ કરો.

જરૂર મુજબ બે મોડ

“Standard”માં લંબાઈ, અક્ષર પ્રકારો, પાસવર્ડ દેખાવ અને આપમેળે નકલ પસંદ કરી શકાય.

“Safer” વધારાની સુરક્ષા આપે છે:

  • ન્યૂનતમ: 24 અક્ષરો; લંબાઈ વધારી શકાય.
  • મોટા અને નાના અક્ષરો, આંકડા અને ચિહ્નો સામેલ.
  • પાસવર્ડ પૂર્વદર્શન કે ક્લિપબોર્ડમાં નકલ નહીં.
  • માત્ર HTTPS જેવા સુરક્ષિત સંદર્ભમાં સીધું ભરવું.
  • ટૅબ છુપાય કે પાનું છોડો ત્યારે સ્ક્રિપ્ટનો અસ્થાયી ડેટા સાફ થાય.

મોડ બદલતાં “Standard” પસંદગીઓ જળવાય છે.

તમને અનુરૂપ ઇન્ટરફેસ

  • મૂળભૂત ઘેરી થીમ અથવા વાદળી થીમ.
  • સંકેલી શકાય તેવા વિભાગોમાં સેટિંગ.
  • તરતું બટન અને ખાનાંના બટનો અલગ છુપાવી શકાય.
  • 46 ભાષા અને પ્રાદેશિક રૂપોની પસંદગી.
  • સ્ક્રિપ્ટ વ્યવસ્થાપક મેનુમાંથી નિર્માણ અને સેટિંગ.

સ્થાપન

  1. યુઝરસ્ક્રિપ્ટ વ્યવસ્થાપકથી ઇન્સ્ટોલ કરો. ભલામણ: Tampermonkey.
  2. તરતા બટન કે વ્યવસ્થાપક મેનુથી સેટિંગ ખોલીને વિકલ્પો પસંદ કરો.
  3. પાસવર્ડ ખાના પાસેના બટનથી સીધું ભરો.

ગોપનીયતા અને મર્યાદાઓ

નિર્માણ સ્થાનિક છે: સ્ક્રિપ્ટ નેટવર્ક વિનંતી મોકલતી નથી કે પાસવર્ડ કાયમી રાખતી નથી. વ્યવસ્થાપક માત્ર પસંદગીઓ સાચવે છે. SigilPass જનરેટર છે, પાસવર્ડ તિજોરી નહીં.

ફોર્મ મેળવનારી સાઇટ ભરેલો પાસવર્ડ વાંચી શકે છે. “Safer” ઇન્ટરફેસ અને ક્લિપબોર્ડમાં ખુલાસો ઘટાડે છે; દૂષિત સાઇટને વિશ્વસનીય બનાવતું નથી.
