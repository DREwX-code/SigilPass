SigilPass

SigilPass membuat kata sandi acak langsung di peramban. Atur panjang dan karakter, isi formulir sekali klik, atau gunakan “Safer” untuk pengisian tanpa tampilan dan penyalinan.

Kata sandi siap digunakan

  • Pembuatan aman secara kriptografis : Web Crypto tanpa beralih ke pembangkit acak tidak aman.
  • Panjang dapat diatur : 12–64 karakter dengan pilihan huruf besar, angka dan simbol.
  • Pengisian langsung : tombol di samping kolom kata sandi, termasuk kolom konfirmasi yang terdeteksi.
  • Indikator entropi : perkiraan konservatif dalam bit dan jumlah kombinasi.
  • Salin otomatis opsional : mati secara bawaan; aktifkan di pengaturan jika perlu.

Dua mode sesuai kebutuhan

“Standard” memungkinkan pemilihan panjang, jenis karakter, tampilan kata sandi dan salin otomatis.

“Safer” menerapkan perlindungan tambahan:

  • Minimum: 24 karakter, panjang dapat ditambah.
  • Termasuk huruf besar, huruf kecil, angka dan simbol.
  • Tanpa pratinjau kata sandi atau penyalinan ke papan klip.
  • Hanya pengisian langsung dalam konteks aman seperti HTTPS.
  • Pembersihan data sementara script saat tab disembunyikan atau halaman ditinggalkan.

Preferensi “Standard” tetap tersimpan saat berganti mode.

Antarmuka yang menyesuaikan

  • Tema gelap bawaan atau tema biru.
  • Pengaturan dalam bagian yang dapat dilipat.
  • Tombol mengambang dan tombol kolom dapat disembunyikan terpisah.
  • Pilihan 46 bahasa dan variasi wilayah.
  • Pembuatan dan pengaturan dari menu pengelola script.

Instalasi

  1. Pasang script dengan pengelola userscript. Rekomendasi: Tampermonkey.
  2. Buka pengaturan dari tombol mengambang atau menu pengelola lalu pilih opsi.
  3. Gunakan tombol di samping kolom kata sandi untuk mengisi langsung.

Privasi dan batasan

Pembuatan bersifat lokal: script tidak mengirim permintaan jaringan atau menyimpan kata sandi secara permanen. Pengelola hanya menyimpan preferensi. SigilPass adalah generator, bukan brankas kata sandi.

Situs penerima formulir dapat membaca kata sandi yang diisikan. “Safer” mengurangi paparan di antarmuka dan papan klip; tidak menjadikan situs berbahaya tepercaya.
