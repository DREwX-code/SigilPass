SigilPass

SigilPass直接在瀏覽器中產生隨機密碼。自訂長度和字元，一鍵填寫表單，或啟用“Safer”模式，在不顯示、不複製密碼的情況下直接填入。

隨時可用的密碼

  • 密碼學安全產生 : 使用Web Crypto，不會退回不安全的隨機產生器。
  • 自訂長度 : 12至64個字元，可選擇大寫字母、數字和符號。
  • 直接填入 : 在密碼欄位及偵測到的確認欄位旁提供按鈕。
  • 熵指標 : 保守估算的位元數及可能組合數。
  • 可選自動複製 : 預設關閉，需要時可在設定中啟用。

依需求選擇兩種模式

“Standard”模式可選擇長度、字元類別、密碼顯示及自動複製。

“Safer”模式提供額外保護：

  • 最少：24個字元，可繼續增加長度。
  • 包含大寫字母、小寫字母、數字和符號。
  • 不預覽密碼，也不複製到剪貼簿。
  • 僅在HTTPS等安全環境中直接填入。
  • 分頁隱藏或離開頁面時，清理腳本的暫存資料。

切換模式時保留“Standard”偏好設定。

適合你的介面

  • 預設深色主題或藍色主題。
  • 設定按可摺疊區段整理。
  • 浮動按鈕和欄位按鈕可分別隱藏。
  • 在設定中選擇46種語言及地區變體。
  • 透過使用者腳本管理器選單存取產生功能和設定。

安裝

  1. 使用使用者腳本管理器安裝腳本。建議: Tampermonkey。
  2. 透過浮動按鈕或管理器選單開啟設定，選擇需要的選項。
  3. 點擊密碼欄位旁的按鈕直接填入。

隱私與限制

密碼在本機產生：腳本不傳送網路請求，也不永久儲存密碼。管理器僅儲存偏好設定。SigilPass是產生器，不是密碼保管庫。

接收表單的網站可以讀取填入的密碼。“Safer”減少介面與剪貼簿中的暴露，但不會讓惡意網站變得可信。
