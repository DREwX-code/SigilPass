SigilPass

SigilPass ബ്രൗസറിൽത്തന്നെ ക്രമരഹിത പാസ്‌വേഡുകൾ സൃഷ്ടിക്കുന്നു. നീളവും അക്ഷരങ്ങളും ക്രമീകരിച്ച് ഒറ്റ ക്ലിക്കിൽ ഫോമുകൾ നിറയ്ക്കുക, അല്ലെങ്കിൽ കാണിക്കലും പകർത്തലും ഇല്ലാതെ “Safer” ഉപയോഗിക്കുക.

ഉപയോഗിക്കാൻ തയ്യാറായ പാസ്‌വേഡ്

  • ക്രിപ്‌റ്റോഗ്രാഫിക് സുരക്ഷയുള്ള സൃഷ്ടി : Web Crypto; സുരക്ഷിതമല്ലാത്ത ക്രമരഹിത ജനറേറ്ററിലേക്കു മാറില്ല.
  • ക്രമീകരിക്കാവുന്ന നീളം : 12–64 അക്ഷരങ്ങൾ; വലിയ അക്ഷരങ്ങൾ, അക്കങ്ങൾ, ചിഹ്നങ്ങൾ തിരഞ്ഞെടുക്കാം.
  • നേരിട്ട് നിറയ്ക്കൽ : കണ്ടെത്തിയ സ്ഥിരീകരണ ഫീൽഡുകൾ ഉൾപ്പെടെ പാസ്‌വേഡ് ഫീൽഡുകൾക്കരികിൽ ബട്ടണുകൾ.
  • എൻട്രോപ്പി സൂചകം : ചെറിയ ടൂൾടിപ്പിൽ ബിറ്റുകളും സാധ്യമായ സംയോജനങ്ങളും സംബന്ധിച്ച കരുതലോടെയുള്ള കണക്ക്.
  • ഐച്ഛിക സ്വയമേവ പകർത്തൽ : സ്വതവേ ഓഫാണ്; വേണമെങ്കിൽ ക്രമീകരണങ്ങളിൽ ഓണാക്കാം.

ആവശ്യത്തിനനുസരിച്ച് രണ്ട് മോഡുകൾ

“Standard” നീളം, അക്ഷരവിഭാഗങ്ങൾ, പാസ്‌വേഡ് കാഴ്ച, സ്വയമേവ പകർത്തൽ എന്നിവ തിരഞ്ഞെടുക്കാൻ അനുവദിക്കുന്നു.

“Safer” കൂടുതൽ സംരക്ഷണം നൽകുന്നു:

  • കുറഞ്ഞത്: 24 അക്ഷരങ്ങൾ; നീളം കൂട്ടാം.
  • വലിയ, ചെറിയ അക്ഷരങ്ങൾ, അക്കങ്ങൾ, ചിഹ്നങ്ങൾ ഉൾപ്പെടും.
  • പാസ്‌വേഡ് പ്രിവ്യൂവോ ക്ലിപ്പ്ബോർഡിലേക്കുള്ള പകർപ്പോ ഇല്ല.
  • HTTPS പോലുള്ള സുരക്ഷിത സാഹചര്യത്തിൽ നേരിട്ട് നിറയ്ക്കൽ മാത്രം.
  • ടാബ് മറയുമ്പോഴോ പേജ് വിടുമ്പോഴോ താൽക്കാലിക സ്ക്രിപ്റ്റ് ഡാറ്റ നീക്കും.

മോഡ് മാറ്റുമ്പോഴും “Standard” മുൻഗണനകൾ നിലനിൽക്കും.

നിങ്ങൾക്കനുസരിച്ചുള്ള ഇന്റർഫേസ്

  • സ്വതവേ ഇരുണ്ട തീം; അല്ലെങ്കിൽ നീല തീം.
  • ചുരുക്കാവുന്ന വിഭാഗങ്ങളിലുള്ള ക്രമീകരണങ്ങൾ.
  • ഫ്ലോട്ടിംഗ് ബട്ടണും ഫീൽഡ് ബട്ടണുകളും വെവ്വേറെ മറയ്ക്കാം.
  • 46 ഭാഷകളും പ്രാദേശിക വകഭേദങ്ങളും തിരഞ്ഞെടുക്കാം.
  • സ്ക്രിപ്റ്റ് മാനേജർ മെനുവിൽനിന്ന് സൃഷ്ടിയും ക്രമീകരണങ്ങളും.

ഇൻസ്റ്റാളേഷൻ

  1. യൂസർസ്ക്രിപ്റ്റ് മാനേജർ വഴി ഇൻസ്റ്റാൾ ചെയ്യുക. ശുപാർശ: Tampermonkey.
  2. ഫ്ലോട്ടിംഗ് ബട്ടണിൽനിന്നോ മാനേജർ മെനുവിൽനിന്നോ ക്രമീകരണങ്ങൾ തുറന്ന് ഓപ്ഷനുകൾ തിരഞ്ഞെടുക്കുക.
  3. നേരിട്ട് നിറയ്ക്കാൻ പാസ്‌വേഡ് ഫീൽഡിനരികിലെ ബട്ടൺ ഉപയോഗിക്കുക.

സ്വകാര്യതയും പരിമിതികളും

സൃഷ്ടി പ്രാദേശികമാണ്: സ്ക്രിപ്റ്റ് നെറ്റ്‌വർക്ക് അഭ്യർത്ഥനകൾ അയയ്ക്കുകയോ പാസ്‌വേഡുകൾ സ്ഥിരമായി സൂക്ഷിക്കുകയോ ചെയ്യുന്നില്ല. മാനേജർ മുൻഗണനകൾ മാത്രമേ സൂക്ഷിക്കൂ. SigilPass ജനറേറ്ററാണ്, പാസ്‌വേഡ് നിലവറയല്ല.

ഫോം സ്വീകരിക്കുന്ന സൈറ്റിന് നിറച്ച പാസ്‌വേഡ് വായിക്കാം. “Safer” ഇന്റർഫേസിലും ക്ലിപ്പ്ബോർഡിലും വെളിപ്പെടൽ കുറയ്ക്കുന്നു; ദുഷ്ട സൈറ്റിനെ വിശ്വസനീയമാക്കില്ല.
