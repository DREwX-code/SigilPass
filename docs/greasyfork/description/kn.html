SigilPass

SigilPass ಬ್ರೌಸರ್‌ನಲ್ಲೇ ಯಾದೃಚ್ಛಿಕ ಪಾಸ್‌ವರ್ಡ್‌ಗಳನ್ನು ರಚಿಸುತ್ತದೆ. ಉದ್ದ ಮತ್ತು ಅಕ್ಷರಗಳನ್ನು ಆಯ್ಕೆಮಾಡಿ, ಒಂದೇ ಕ್ಲಿಕ್‌ನಲ್ಲಿ ಫಾರ್ಮ್ ತುಂಬಿ ಅಥವಾ ಪ್ರದರ್ಶನ ಮತ್ತು ನಕಲು ಇಲ್ಲದೆ “Safer” ಬಳಸಿ.

ಬಳಕೆಗೆ ಸಿದ್ಧ ಪಾಸ್‌ವರ್ಡ್

  • ಕ್ರಿಪ್ಟೋಗ್ರಾಫಿಕ್ ಸುರಕ್ಷಿತ ರಚನೆ : Web Crypto ಬಳಕೆ; ಅಸುರಕ್ಷಿತ ಯಾದೃಚ್ಛಿಕ ಜನರೇಟರ್‌ಗೆ ಬದಲಾಗುವುದಿಲ್ಲ.
  • ಬದಲಾಯಿಸಬಹುದಾದ ಉದ್ದ : 12–64 ಅಕ್ಷರಗಳು; ದೊಡ್ಡಕ್ಷರ, ಅಂಕಿ ಮತ್ತು ಸಂಕೇತಗಳ ಆಯ್ಕೆ.
  • ನೇರ ಭರ್ತಿ : ಗುರುತಿಸಿದ ದೃಢೀಕರಣ ಕ್ಷೇತ್ರಗಳೂ ಸೇರಿದಂತೆ ಪಾಸ್‌ವರ್ಡ್ ಕ್ಷೇತ್ರಗಳ ಪಕ್ಕದಲ್ಲಿ ಬಟನ್‌ಗಳು.
  • ಎಂಟ್ರೋಪಿ ಸೂಚಕ : ಬಿಟ್‌ಗಳು ಮತ್ತು ಸಾಧ್ಯ ಸಂಯೋಜನೆಗಳ ಎಚ್ಚರಿಕೆಯ ಅಂದಾಜು.
  • ಐಚ್ಛಿಕ ಸ್ವಯಂಚಾಲಿತ ನಕಲು : ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಆಫ್; ಬೇಕಾದರೆ ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ ಆನ್ ಮಾಡಿ.

ಅಗತ್ಯಕ್ಕೆ ತಕ್ಕ ಎರಡು ಮೋಡ್‌ಗಳು

“Standard”ನಲ್ಲಿ ಉದ್ದ, ಅಕ್ಷರ ವರ್ಗಗಳು, ಪಾಸ್‌ವರ್ಡ್ ಪ್ರದರ್ಶನ ಮತ್ತು ಸ್ವಯಂಚಾಲಿತ ನಕಲು ಆಯ್ಕೆಮಾಡಬಹುದು.

“Safer” ಹೆಚ್ಚುವರಿ ರಕ್ಷಣೆ ನೀಡುತ್ತದೆ:

  • ಕನಿಷ್ಠ: 24 ಅಕ್ಷರಗಳು; ಉದ್ದ ಹೆಚ್ಚಿಸಬಹುದು.
  • ದೊಡ್ಡ ಮತ್ತು ಚಿಕ್ಕ ಅಕ್ಷರಗಳು, ಅಂಕಿಗಳು, ಸಂಕೇತಗಳು ಸೇರಿವೆ.
  • ಪಾಸ್‌ವರ್ಡ್ ಪೂರ್ವವೀಕ್ಷಣೆ ಅಥವಾ ಕ್ಲಿಪ್‌ಬೋರ್ಡ್ ನಕಲು ಇಲ್ಲ.
  • HTTPSನಂತಹ ಸುರಕ್ಷಿತ ಸಂದರ್ಭದಲ್ಲಿ ನೇರ ಭರ್ತಿ ಮಾತ್ರ.
  • ಟ್ಯಾಬ್ ಮರೆವಾದಾಗ ಅಥವಾ ಪುಟ ಬಿಟ್ಟಾಗ ತಾತ್ಕಾಲಿಕ ಸ್ಕ್ರಿಪ್ಟ್ ಡೇಟಾ ತೆರವು.

ಮೋಡ್ ಬದಲಾಯಿಸಿದರೂ “Standard” ಆದ್ಯತೆಗಳು ಉಳಿಯುತ್ತವೆ.

ನಿಮಗೆ ಹೊಂದುವ ಇಂಟರ್‌ಫೇಸ್

  • ಪೂರ್ವನಿಯೋಜಿತ ಗಾಢ ಥೀಮ್ ಅಥವಾ ನೀಲಿ ಥೀಮ್.
  • ಮಡಚಬಹುದಾದ ವಿಭಾಗಗಳಲ್ಲಿ ಸೆಟ್ಟಿಂಗ್‌ಗಳು.
  • ತೇಲುವ ಬಟನ್ ಮತ್ತು ಕ್ಷೇತ್ರ ಬಟನ್‌ಗಳನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ಮರೆಮಾಡಬಹುದು.
  • 46 ಭಾಷೆಗಳು ಮತ್ತು ಪ್ರಾದೇಶಿಕ ರೂಪಗಳ ಆಯ್ಕೆ.
  • ಸ್ಕ್ರಿಪ್ಟ್ ನಿರ್ವಾಹಕ ಮೆನುವಿನಿಂದ ರಚನೆ ಮತ್ತು ಸೆಟ್ಟಿಂಗ್‌ಗಳು.

ಸ್ಥಾಪನೆ

  1. ಯೂಸರ್‌ಸ್ಕ್ರಿಪ್ಟ್ ನಿರ್ವಾಹಕದಿಂದ ಸ್ಥಾಪಿಸಿ. ಶಿಫಾರಸು: Tampermonkey.
  2. ತೇಲುವ ಬಟನ್ ಅಥವಾ ನಿರ್ವಾಹಕ ಮೆನುವಿನಿಂದ ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು ತೆರೆದು ಆಯ್ಕೆಗಳನ್ನು ಆರಿಸಿ.
  3. ಪಾಸ್‌ವರ್ಡ್ ಕ್ಷೇತ್ರದ ಪಕ್ಕದ ಬಟನ್‌ನಿಂದ ನೇರವಾಗಿ ತುಂಬಿ.

ಗೌಪ್ಯತೆ ಮತ್ತು ಮಿತಿಗಳು

ರಚನೆ ಸ್ಥಳೀಯವಾಗಿದೆ: ಸ್ಕ್ರಿಪ್ಟ್ ನೆಟ್‌ವರ್ಕ್ ವಿನಂತಿಗಳನ್ನು ಕಳುಹಿಸುವುದಿಲ್ಲ ಮತ್ತು ಪಾಸ್‌ವರ್ಡ್‌ಗಳನ್ನು ಶಾಶ್ವತವಾಗಿ ಉಳಿಸುವುದಿಲ್ಲ. ನಿರ್ವಾಹಕ ಆದ್ಯತೆಗಳನ್ನಷ್ಟೇ ಉಳಿಸುತ್ತಾನೆ. SigilPass ಜನರೇಟರ್, ಪಾಸ್‌ವರ್ಡ್ ಭಂಡಾರವಲ್ಲ.

ಫಾರ್ಮ್ ಪಡೆಯುವ ಸೈಟ್ ತುಂಬಿದ ಪಾಸ್‌ವರ್ಡ್ ಓದಬಹುದು. “Safer” ಇಂಟರ್‌ಫೇಸ್ ಮತ್ತು ಕ್ಲಿಪ್‌ಬೋರ್ಡ್‌ನ ಬಹಿರಂಗತೆಯನ್ನು ಕಡಿಮೆ ಮಾಡುತ್ತದೆ; ದುರುದ್ದೇಶದ ಸೈಟ್‌ನ್ನು ನಂಬಿಕೆಗೆ ಅರ್ಹವಾಗಿಸುವುದಿಲ್ಲ.
