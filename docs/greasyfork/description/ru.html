SigilPass

SigilPass создаёт случайные пароли прямо в браузере. Настройте длину и символы, заполняйте формы одним нажатием или включите “Safer” для заполнения без показа и копирования.

Пароль, готовый к использованию

  • Криптографически безопасная генерация : Web Crypto без перехода к небезопасному генератору случайных чисел.
  • Настраиваемая длина : 12–64 символа с заглавными буквами, цифрами и спецсимволами по выбору.
  • Прямое заполнение : кнопки рядом с полями пароля, включая обнаруженные поля подтверждения.
  • Индикатор энтропии : осторожная оценка в битах и числа возможных комбинаций .
  • Необязательное автокопирование : по умолчанию выключено; при необходимости включается в настройках.

Два режима для разных задач

“Standard” позволяет выбрать длину, категории символов, показ пароля и автокопирование.

“Safer” включает дополнительную защиту:

  • Минимум: 24 символов с возможностью увеличить длину.
  • Заглавные и строчные буквы, цифры и спецсимволы.
  • Без предпросмотра и копирования в буфер обмена.
  • Только прямое заполнение в безопасном контексте, например HTTPS.
  • Очистка временных данных скрипта при скрытии вкладки или уходе со страницы.

Настройки “Standard” сохраняются при смене режима.

Настраиваемый интерфейс

  • Тёмная тема по умолчанию или синяя тема.
  • Настройки в сворачиваемых разделах.
  • Плавающую кнопку и кнопки полей можно скрывать отдельно.
  • Выбор из 46 языков и региональных вариантов.
  • Генерация и настройки из меню менеджера скриптов.

Установка

  1. Установите скрипт через менеджер пользовательских скриптов. Рекомендация: Tampermonkey.
  2. Откройте настройки плавающей кнопкой или через меню менеджера и выберите параметры.
  3. Нажмите кнопку рядом с полем пароля для прямого заполнения.

Конфиденциальность и ограничения

Генерация локальная: скрипт не отправляет сетевых запросов и не сохраняет пароли постоянно. Менеджер хранит только настройки. SigilPass — генератор, а не хранилище паролей.

Сайт, принимающий форму, может прочитать заполненный пароль. “Safer” уменьшает раскрытие в интерфейсе и буфере обмена, но не делает вредоносный сайт надёжным.
