SigilPass

SigilPass створює випадкові паролі безпосередньо в браузері. Налаштуйте довжину й символи, заповнюйте форми одним натисканням або використовуйте “Safer” без показу та копіювання.

Пароль, готовий до використання

  • Криптографічно безпечна генерація : Web Crypto без переходу до небезпечного генератора випадкових чисел.
  • Налаштовувана довжина : 12–64 символи з великими літерами, цифрами й спецсимволами на вибір.
  • Пряме заповнення : кнопки біля полів пароля, включно з виявленими полями підтвердження.
  • Індикатор ентропії : обережна оцінка в бітах і кількості можливих комбінацій .
  • Необов’язкове автокопіювання : типово вимкнене; за потреби ввімкніть у налаштуваннях.

Два режими для ваших потреб

“Standard” дозволяє вибрати довжину, категорії символів, показ пароля й автокопіювання.

“Safer” застосовує додатковий захист:

  • Мінімум: 24 символи з можливістю збільшити довжину.
  • Великі й малі літери, цифри та спецсимволи.
  • Без попереднього перегляду та копіювання в буфер обміну.
  • Лише пряме заповнення в безпечному контексті, наприклад HTTPS.
  • Очищення тимчасових даних скрипту, коли вкладку приховано або ви залишаєте сторінку.

Налаштування “Standard” зберігаються під час зміни режиму.

Гнучкий інтерфейс

  • Темна тема типово або синя тема.
  • Налаштування у згортаних розділах.
  • Плаваючу кнопку й кнопки полів можна приховувати окремо.
  • Вибір із 46 мов і регіональних варіантів.
  • Генерація й налаштування з меню менеджера скриптів.

Встановлення

  1. Установіть скрипт через менеджер користувацьких скриптів. Рекомендація: Tampermonkey.
  2. Відкрийте налаштування плаваючою кнопкою або з меню менеджера та виберіть параметри.
  3. Скористайтеся кнопкою біля поля пароля для прямого заповнення.

Конфіденційність та обмеження

Генерація локальна: скрипт не надсилає мережевих запитів і не зберігає паролі постійно. Менеджер зберігає лише налаштування. SigilPass — генератор, а не сховище паролів.

Сайт, що отримує форму, має доступ до заповненого пароля. “Safer” зменшує розкриття в інтерфейсі й буфері обміну, але не робить шкідливий сайт надійним.
