SigilPass

SigilPass, உலாவியிலேயே சீரற்ற கடவுச்சொற்களை உருவாக்குகிறது. நீளம் மற்றும் எழுத்துகளைத் தேர்ந்தெடுத்து ஒரே கிளிக்கில் படிவங்களை நிரப்புங்கள் அல்லது காட்டாமலும் நகலெடுக்காமலும் நிரப்ப “Safer” பயன்படுத்துங்கள்.

பயன்படுத்தத் தயாரான கடவுச்சொல்

  • குறியாக்கவியல் ரீதியாகப் பாதுகாப்பான உருவாக்கம் : Web Crypto பயன்பாடு; பாதுகாப்பற்ற சீரற்ற உருவாக்கிக்குப் பின்வாங்காது.
  • தனிப்பயன் நீளம் : 12–64 எழுத்துகள்; பெரிய எழுத்துகள், எண்கள் மற்றும் குறியீடுகளைத் தேர்ந்தெடுக்கலாம்.
  • நேரடி நிரப்புதல் : கண்டறியப்பட்ட உறுதிப்படுத்தல் புலங்கள் உட்பட கடவுச்சொல் புலங்களருகே பொத்தான்கள்.
  • என்ட்ரோபி காட்டி : சிறு உதவிக்குறிப்பில் பிட்கள் மற்றும் சாத்தியமான சேர்க்கைகளின் எச்சரிக்கையான மதிப்பீடு.
  • விருப்பத் தானியங்கு நகலெடுப்பு : இயல்பாக முடக்கப்பட்டது; தேவைப்பட்டால் அமைப்புகளில் இயக்கலாம்.

தேவைக்கேற்ற இரண்டு முறைகள்

“Standard” முறையில் நீளம், எழுத்துவகைகள், கடவுச்சொல் காட்சி மற்றும் தானியங்கு நகலெடுப்பைத் தேர்ந்தெடுக்கலாம்.

“Safer” கூடுதல் பாதுகாப்புகளை வழங்குகிறது:

  • குறைந்தபட்சம்: 24 எழுத்துகள்; நீளத்தை அதிகரிக்கலாம்.
  • பெரிய மற்றும் சிறிய எழுத்துகள், எண்கள், குறியீடுகள் அடங்கும்.
  • கடவுச்சொல் முன்னோட்டமும் கிளிப்போர்டு நகலெடுப்பும் இல்லை.
  • HTTPS போன்ற பாதுகாப்பான சூழலில் நேரடி நிரப்புதல் மட்டும்.
  • தாவல் மறையும்போது அல்லது பக்கத்தை விட்டு வெளியேறும்போது தற்காலிக ஸ்கிரிப்ட் தரவு நீக்கப்படும்.

முறையை மாற்றும்போதும் “Standard” விருப்பங்கள் பாதுகாக்கப்படும்.

உங்களுக்கேற்ற இடைமுகம்

  • இயல்பாக இருள் தோற்றம் அல்லது நீலத் தோற்றம்.
  • மடிக்கக்கூடிய பிரிவுகளில் அமைப்புகள்.
  • மிதக்கும் பொத்தானையும் புலப் பொத்தான்களையும் தனித்தனியாக மறைக்கலாம்.
  • அமைப்புகளில் 46 மொழிகள் மற்றும் வட்டார மாறுபாடுகள்.
  • ஸ்கிரிப்ட் மேலாளர் பட்டியலிலிருந்து உருவாக்கமும் அமைப்புகளும்.

நிறுவல்

  1. பயனர் ஸ்கிரிப்ட் மேலாளருடன் நிறுவுங்கள். பரிந்துரை: Tampermonkey。
  2. மிதக்கும் பொத்தான் அல்லது மேலாளர் பட்டியலிலிருந்து அமைப்புகளைத் திறந்து விருப்பங்களைத் தேர்ந்தெடுக்கவும்.
  3. நேரடியாக நிரப்ப கடவுச்சொல் புலத்தருகிலுள்ள பொத்தானைப் பயன்படுத்தவும்.

தனியுரிமையும் வரம்புகளும்

உருவாக்கம் உள்ளூரில் நடைபெறுகிறது: வலைப்பிணையக் கோரிக்கைகள் அனுப்பப்படாது; கடவுச்சொற்கள் நிரந்தரமாகச் சேமிக்கப்படாது. மேலாளர் விருப்பங்களை மட்டுமே சேமிக்கிறார். SigilPass உருவாக்கி; கடவுச்சொல் பெட்டகம் அல்ல.

படிவத்தைப் பெறும் தளம் நிரப்பிய கடவுச்சொல்லைப் படிக்கலாம். “Safer” இடைமுகம் மற்றும் கிளிப்போர்டு வெளிப்பாட்டைக் குறைக்கிறது; தீங்கிழைக்கும் தளத்தை நம்பகமானதாக்காது.
