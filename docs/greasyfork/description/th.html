SigilPass

SigilPass สร้างรหัสผ่านสุ่มในเบราว์เซอร์โดยตรง ปรับความยาวและอักขระ กรอกแบบฟอร์มในคลิกเดียว หรือใช้ “Safer” เพื่อกรอกโดยไม่แสดงหรือคัดลอก

รหัสผ่านพร้อมใช้

  • สร้างอย่างปลอดภัยทางการเข้ารหัส : ใช้ Web Crypto โดยไม่ย้อนกลับไปใช้ตัวสร้างสุ่มที่ไม่ปลอดภัย
  • ปรับความยาวได้ : 12–64 ตัวอักษร เลือกตัวพิมพ์ใหญ่ ตัวเลข และสัญลักษณ์ได้
  • กรอกโดยตรง : ปุ่มข้างช่องรหัสผ่าน รวมถึงช่องยืนยันที่ตรวจพบ
  • ตัวบอกเอนโทรปี : ค่าประมาณแบบระมัดระวังในหน่วยบิตและจำนวนชุดค่าที่เป็นไปได้
  • คัดลอกอัตโนมัติแบบเลือกได้ : ปิดโดยค่าเริ่มต้น เปิดในการตั้งค่าเมื่อต้องการ

สองโหมดตามการใช้งาน

“Standard” ให้เลือกความยาว ประเภทอักขระ การแสดงรหัสผ่าน และการคัดลอกอัตโนมัติ

“Safer” เพิ่มการป้องกัน:

  • ขั้นต่ำ: 24 ตัวอักษร และเพิ่มความยาวได้
  • รวมตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก ตัวเลข และสัญลักษณ์
  • ไม่แสดงตัวอย่างรหัสผ่านหรือคัดลอกไปคลิปบอร์ด
  • กรอกโดยตรงเฉพาะในบริบทปลอดภัย เช่น HTTPS
  • ล้างข้อมูลชั่วคราวของสคริปต์เมื่อซ่อนแท็บหรือออกจากหน้า

การตั้งค่า “Standard” จะคงอยู่เมื่อเปลี่ยนโหมด

อินเทอร์เฟซที่ปรับได้

  • ธีมมืดเป็นค่าเริ่มต้น หรือธีมสีน้ำเงิน
  • การตั้งค่าแบ่งเป็นส่วนพับได้
  • ซ่อนปุ่มลอยและปุ่มข้างช่องแยกกันได้
  • เลือกได้ 46 ภาษาและรูปแบบภูมิภาค
  • สร้างรหัสผ่านและเข้าการตั้งค่าจากเมนูตัวจัดการสคริปต์

การติดตั้ง

  1. ติดตั้งผ่านตัวจัดการสคริปต์ผู้ใช้ คำแนะนำ: Tampermonkey
  2. เปิดการตั้งค่าจากปุ่มลอยหรือเมนูตัวจัดการ แล้วเลือกตัวเลือก
  3. ใช้ปุ่มข้างช่องรหัสผ่านเพื่อกรอกโดยตรง

ความเป็นส่วนตัวและข้อจำกัด

สร้างในเครื่อง: สคริปต์ไม่ส่งคำขอเครือข่ายและไม่เก็บรหัสผ่านถาวร ตัวจัดการบันทึกเฉพาะการตั้งค่า SigilPass เป็นตัวสร้าง ไม่ใช่คลังรหัสผ่าน

เว็บไซต์ที่รับแบบฟอร์มอ่านรหัสผ่านที่กรอกได้ “Safer” ลดการเปิดเผยในอินเทอร์เฟซและคลิปบอร์ด แต่ไม่ทำให้เว็บอันตรายเชื่อถือได้
