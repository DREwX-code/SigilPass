SigilPass

SigilPassは、ブラウザー内でランダムなパスワードを生成します。長さや文字を調整し、ワンクリックでフォームに入力できます。“Safer”なら表示もコピーもせずに直接入力できます。

すぐ使えるパスワード

  • 暗号学的に安全な生成 : Web Cryptoを使用し、安全でない乱数生成には切り替えません。
  • 長さを調整可能 : 12～64文字。大文字、数字、記号を選択できます。
  • 直接入力 : パスワード欄と検出された確認欄の横に入力ボタンを配置します。
  • エントロピー表示 : ビット数と可能な組み合わせ数の保守的な推定。
  • 任意の自動コピー : 初期状態は無効です。必要に応じて設定から有効にできます。

用途に応じた2つのモード

“Standard”では長さ、文字の種類、パスワードの表示、自動コピーを選べます。

“Safer”では追加の保護が適用されます。

  • 最小：24文字。さらに長くすることもできます。
  • 大文字、小文字、数字、記号をすべて含めます。
  • パスワードのプレビューもクリップボードへのコピーもしません。
  • HTTPSなどの安全なコンテキストでの直接入力のみ。
  • タブが非表示になったときやページを離れたときに、スクリプトの一時データを消去します。

モードを切り替えても“Standard”の設定は保持されます。

使いやすく調整できる画面

  • 初期設定はダークテーマまたは青いテーマ。
  • 設定は折りたたみ可能なセクションに整理。
  • フローティングボタンと入力欄のボタンは個別に非表示にできます。
  • 設定から46の言語・地域別バリエーションを選択。
  • スクリプト管理ツールのメニューから生成と設定にアクセスできます。

インストール

  1. ユーザースクリプト管理ツールでインストールしてください。おすすめ: Tampermonkey。
  2. フローティングボタンまたは管理ツールのメニューから設定を開き、オプションを選びます。
  3. パスワード欄の横のボタンを使って直接入力します。

プライバシーと制限

生成はローカルで行われます。スクリプトはネットワーク要求を送信せず、パスワードを永続保存しません。管理ツールに保存するのは設定だけです。SigilPassは生成ツールであり、パスワード保管庫ではありません。

フォームに入力したパスワードは、そのサイトから読み取れます。“Safer”は画面とクリップボードでの露出を減らしますが、悪意あるサイトを安全にはしません。

ソースコードとサポート
