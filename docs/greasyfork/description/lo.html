SigilPass

SigilPass ສ້າງລະຫັດຜ່ານສຸ່ມໃນບຣາວເຊີ. ປັບຄວາມຍາວແລະຕົວອັກສອນ ຕື່ມແບບຟອມດ້ວຍຄລິກດຽວ ຫຼືໃຊ້ “Safer” ໂດຍບໍ່ສະແດງຫຼືຄັດລອກ.

ລະຫັດຜ່ານພ້ອມໃຊ້

  • ສ້າງຢ່າງປອດໄພທາງການເຂົ້າລະຫັດ : ໃຊ້ Web Crypto ໂດຍບໍ່ຍ້ອນໄປໃຊ້ຕົວສຸ່ມທີ່ບໍ່ປອດໄພ.
  • ປັບຄວາມຍາວໄດ້ : 12–64 ຕົວອັກສອນ ເລືອກຕົວໃຫຍ່ ຕົວເລກ ແລະສັນຍາລັກ.
  • ຕື່ມໂດຍກົງ : ປຸ່ມຂ້າງຊ່ອງລະຫັດຜ່ານ ລວມຊ່ອງຢືນຢັນທີ່ກວດພົບ.
  • ຕົວຊີ້ເອນໂທຣປີ : ຄາດຄະເນແບບລະມັດລະວັງເປັນບິດ ແລະຈຳນວນຮູບແບບ.
  • ຄັດລອກອັດຕະໂນມັດເປັນທາງເລືອກ : ປິດເປັນຄ່າເລີ່ມຕົ້ນ ເປີດໃນການຕັ້ງຄ່າໄດ້.

ສອງໂໝດຕາມຄວາມຕ້ອງການ

“Standard” ໃຫ້ເລືອກຄວາມຍາວ ປະເພດຕົວອັກສອນ ການສະແດງ ແລະຄັດລອກອັດຕະໂນມັດ.

“Safer” ເພີ່ມການປ້ອງກັນ:

  • ຂັ້ນຕ່ຳ: 24 ຕົວອັກສອນ ເພີ່ມຄວາມຍາວໄດ້.
  • ມີຕົວໃຫຍ່ ຕົວນ້ອຍ ຕົວເລກ ແລະສັນຍາລັກ.
  • ບໍ່ສະແດງລະຫັດຜ່ານ ຫຼືຄັດລອກໃສ່ຄລິບບອດ.
  • ຕື່ມໂດຍກົງສະເພາະໃນບໍລິບົດປອດໄພ ເຊັ່ນ HTTPS.
  • ລ້າງຂໍ້ມູນຊົ່ວຄາວເມື່ອແທັບຖືກເຊື່ອງ ຫຼືອອກຈາກໜ້າ.

ຄ່າ “Standard” ຍັງຄົງຢູ່ເມື່ອປ່ຽນໂໝດ.

ໜ້າຕາທີ່ປັບໄດ້

  • ໂໝດມືດເປັນຄ່າເລີ່ມຕົ້ນ ຫຼືສີຟ້າ.
  • ການຕັ້ງຄ່າໃນພາກທີ່ພັບໄດ້.
  • ເຊື່ອງປຸ່ມລອຍແລະປຸ່ມຊ່ອງແຍກກັນໄດ້.
  • ເລືອກ 46 ພາສາແລະຮູບແບບພາກພື້ນ.
  • ສ້າງແລະຕັ້ງຄ່າຈາກເມນູຕົວຈັດການສະຄຣິບ.

ການຕິດຕັ້ງ

  1. ຕິດຕັ້ງຜ່ານຕົວຈັດການສະຄຣິບຜູ້ໃຊ້. ຄຳແນະນຳ: Tampermonkey.
  2. ເປີດການຕັ້ງຄ່າຈາກປຸ່ມລອຍຫຼືເມນູ ແລ້ວເລືອກຕົວເລືອກ.
  3. ໃຊ້ປຸ່ມຂ້າງຊ່ອງລະຫັດຜ່ານເພື່ອຕື່ມໂດຍກົງ.

ຄວາມເປັນສ່ວນຕົວແລະຂໍ້ຈຳກັດ

ສ້າງພາຍໃນເຄື່ອງ: ສະຄຣິບບໍ່ສົ່ງຄຳຂໍເຄືອຂ່າຍ ຫຼືເກັບລະຫັດຜ່ານຖາວອນ. ເກັບແຕ່ການຕັ້ງຄ່າ. SigilPass ເປັນຕົວສ້າງ ບໍ່ແມ່ນຄັງລະຫັດຜ່ານ.

ເວັບທີ່ຮັບຟອມອ່ານລະຫັດຜ່ານທີ່ຕື່ມໄດ້. “Safer” ຫຼຸດການເປີດເຜີຍໃນໜ້າຕາແລະຄລິບບອດ ບໍ່ເຮັດໃຫ້ເວັບອັນຕະລາຍໜ້າເຊື່ອຖື.

ລະຫັດຕົ້ນສະບັບແລະການຊ່ວຍເຫຼືອ

ເບິ່ງລະຫັດຕົ້ນສະບັບໃນ GitHub ຫຼືແຈ້ງບັນຫາ. ລະບຸບຣາວເຊີ ຕົວຈັດການ ແລະຂັ້ນຕອນເຮັດຊ້ຳ ໂດຍບໍ່ແບ່ງປັນລະຫັດຜ່ານ.
